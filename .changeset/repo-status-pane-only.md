`repo-status` now lives in one place: the Repo status pane beside the chat. The pane opens by itself when a session starts, so the status, the in-flight work and the next-prompt buttons are always in view. The line above the prompt is gone, and `/repo-status` no longer prints a copy of the status into the transcript; it just reopens the pane if you closed it.
